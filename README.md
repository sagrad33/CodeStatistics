# Code Statistics — Анализатор C++ кода для VS Code

Расширение для Visual Studio Code, которое выполняет статический анализ исходного кода на языке C++ в режиме реального времени. Плагин открывает боковую панель (`Webview`) и автоматически пересчитывает метрики при редактировании кода или переключении между файлами.

## Возможности плагина
* **Подсчёт структуры кода:** общее количество строк, строк с комментариями, функций, переменных, условных операторов `if`, циклов `for` и `while`.
* **Контроль оформления:** вычисление максимальной длины строки в символах.
* **Оценка потребления памяти:**
  * подсчёт статической памяти (примитивные типы, массивы, указатели);
  * подсчёт динамической памяти (`new`, `new[]` с поддержкой переменных размера, `malloc`).
* **Проверка утечек памяти:** сравнение количества завершённых операций выделения (`new`, `malloc`) и освобождения памяти (`delete`, `delete[]`, `free`).

## Структура проекта
* `extension.js` — основной модуль расширения с логикой анализатора и генерацией интерфейса.
* `package.json` — манифест расширения (точки активации и регистрация команд).
* `test.js` — набор модульных тестов для проверки работы парсера.
* `docs/` — сгенерированная JSDoc-документация по методам проекта.
* `.vscode/launch.json` — конфигурация запуска отладки в VS Code.

## Запуск и тестирование
1. Откройте папку проекта в **Visual Studio Code**.
2. Нажмите `F5` для запуска окна отладки (**Extension Development Host**).
3. Откройте любой файл с расширением `.cpp`, нажмите `Ctrl + Shift + P` и выберите команду **`Code Statistics: Analyze`**.
4. Для запуска автоматических тестов выполните в терминале:
   ```bash
   node test.js
   ```
5. Для просмотра документации откройте в браузере файл `docs/index.html`.
